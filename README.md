# Python CI Project

A simple python project demostrating continous Integration.

## Features

- Addition Function
- Subtraction function
- Automated test using pytest

## Requirments

- Python 3
- pytest

## Install dependencies
python3 -m pip install -r requirement.txt

## Run application
python3 app.py

## Run tests
python -m pytest -v

## Project Status
This project uses GitHub Action for automated Python testing
